# Game design

Elemental Keep is a single-player farming survival game where players tend crops, defend a farmhouse, and survive enemy waves.

## Core loop
1. Plant elemental seeds on farm plots.
2. Harvest crops when mature to gain elemental resources.
3. Spend resources on turrets and repairs.
4. Survive escalating enemy waves.
5. Save the result to the local leaderboard.

## Elements
Fire, water, earth, wind, ice, and lightning each have distinct combat profiles. The initial playable version includes a data-driven foundation and working basic turret behaviour.

## Difficulty
Early waves focus on swarmer units, then introduce brute and runner enemies. Boss appearances occur at later wave milestones.
